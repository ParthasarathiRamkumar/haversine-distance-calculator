# Haversine Distance Calculator — My First C++ Project

Welcome, everyone!

This is my first C++ project, created to calculate the distance between two geographical points.

**Why did I build this project when similar solutions already exist on the internet?**

I developed this project to automate a real-world calculation that I previously performed manually. Working on it helped me become more familiar with the calculations and understand how to implement them through programming.

I acknowledge that this code is not completely error-free and may have certain limitations. I believe every piece of code has room for improvement, and consistently refining it is the best way to create better versions.
